1. INTRODUCTION                           *tree-sitter-manager-introduction*

tree-sitter-manager.nvim is a lightweight Tree-sitter parser manager for
Neovim. It provides a minimal TUI interface for installing, removing, and
updating Tree-sitter parsers without depending on nvim-treesitter.

Features:~
  - Install parsers directly from Tree-sitter repositories
  - Automatic query file management for syntax highlighting
  - Custom/fork repository support via `setup()`
  - Auto-install parsers on FileType events
  - Works with any plugin manager

==============================================================================
2. REQUIREMENTS                           *tree-sitter-manager-requirements*

Mandatory:~
  - Neovim 0.12+
  - tree-sitter CLI  (must be in $PATH)
  - git
  - C compiler (gcc or clang)

Optional:~
  - Nerd Font (for icons ✅ ❌ 📦)

3. INSTALLATION                           *tree-sitter-manager-installation*

lazy.nvim: >lua
  {
    "romus204/tree-sitter-manager.nvim",
    config = function()
      require("tree-sitter-manager").setup({})
    end
  }
<

vim.pack: >lua
  vim.pack.add({
    { src = "https://github.com/romus204/tree-sitter-manager.nvim" }
  })

  require("tree-sitter-manager").setup({})
<

4. SETUP                                       *tree-sitter-manager-setup*

                                               *tree-sitter-manager.setup()*
>lua
  require("tree-sitter-manager").setup({
    languages        = {},
    assume_installed = {},
    ensure_installed = {},
    auto_install     = false,
    noauto_install   = {},
    highlight        = true,
    nohighlight      = {},
    parser_dir       = vim.fn.stdpath("data") .. "/site/parser",
    query_dir        = vim.fn.stdpath("data") .. "/site/queries",
    -- TUI options
    nerdfont         = true,
    border           = "rounded",
    min_width        = 78,
    min_height       = 40,
    -- tree-sitter-manager.util
    async_size       = 64,
  })
<

`setup()` must be called once before using the plugin.

==============================================================================
5. OPTIONS                                     *tree-sitter-manager-options*

All options are passed as a table to |tree-sitter-manager.setup()|.

------------------------------------------------------------------------------
                                          *tree-sitter-manager-opt-parser_dir*
parser_dir ~
  Type: `string`
  Default: `stdpath("data") .. "/site/parser"`

  Directory where compiled parser `.so`/`.dll` files are stored.
  The parent directory is automatically prepended to 'runtimepath'.

------------------------------------------------------------------------------
                                           *tree-sitter-manager-opt-query_dir*
query_dir ~
  Type: `string`
  Default: `stdpath("data") .. "/site/queries"`

  Directory where query files (`highlights.scm`, etc.) are stored.
  The parent directory is automatically prepended to 'runtimepath'.

------------------------------------------------------------------------------
                                    *tree-sitter-manager-opt-assume_installed*
assume_installed ~
  Type: `table`
  Default: `{}`

  Languages in this list are assumed to be installed. The following will tell
  tree-sitter-manager to never install Neovim's built-in parsers: >lua
    assume_installed = {
      "c", "lua", "markdown", "markdown_inline", "query", "vim", "vimdoc"
    }
<
  Note: tree-sitter-manager parsers often ship with more query files than
  what's available in Neovim.

------------------------------------------------------------------------------
                                    *tree-sitter-manager-opt-ensure_installed*
ensure_installed ~
  Type: `string[]|string`
  Default: `{}`

  List of parsers to install automatically at startup (if not already
  installed). If set to `"all"`, install all parsers. >lua
    ensure_installed = { "lua", "python", "rust" }
    ensure_installed = "all"
<

------------------------------------------------------------------------------
                                        *tree-sitter-manager-opt-auto_install*
auto_install ~
  Type: `boolean`
  Default: `false`

  When `true`, automatically installs a missing parser whenever Neovim
  opens a file whose filetype matches a known language.

------------------------------------------------------------------------------
                                      *tree-sitter-manager-opt-noauto_install*
noauto_install ~
  Type: `string[]`
  Default: `{}`

  Opt-out from automatically installing specified languages when
  `auto_install = true`. For example, if you prefer the built-in Neovim
  parsers: >lua
    noauto_install = {
      "c", "lua", "markdown", "markdown_inline", "query", "vim", "vimdoc"
    }
<

------------------------------------------------------------------------------
                                           *tree-sitter-manager-opt-highlight*
highlight ~
  Type: `boolean|string[]`
  Default: `true`

  Controls Tree-sitter syntax highlighting.
  - `true`      — enable for all installed parsers
  - `false`/`{}` — disable entirely
  - `string[]`  — enable only for the listed languages >lua
    highlight = { "lua", "python" }
<

------------------------------------------------------------------------------
                                         *tree-sitter-manager-opt-nohighlight*
nohighlight ~
  Type: `string[]`
  Default: `{}`

  Exclude specific languages from Tree-sitter highlighting even when
  `highlight = true`. Useful for languages where regex highlighting is
  preferred. >lua
    nohighlight = { "yaml", "zsh" }
<

------------------------------------------------------------------------------
                                            *tree-sitter-manager-opt-nerdfont*
nerdfont ~
  Type: `boolean`
  Default: `true`

  By default, the manager buffer requires Nerd Fonts for emojis and icons. If
  you prefer plain text instead of the glyphs set this to `false`.

------------------------------------------------------------------------------
                                              *tree-sitter-manager-opt-border*
border ~
  Type: `string|table`
  Default: `"rounded"`

  Border style for the TUI window. See |nvim_open_win()| for accepted values.
  Examples: `"rounded"`, `"single"`, `"double"`, `"solid"`, `"none"`.

  To match 'winborder' option set it to `vim.o.winborder` (Neovim 0.11+).

------------------------------------------------------------------------------
                                           *tree-sitter-manager-opt-min-width*
                                           *tree-sitter-manager-opt-min-height*
min_width ~
min_height ~
  Type: `number`

  Minimum size of the TUI window. Default vales: >lua
    min_width = 78
    min_height = 40
>

6. COMMANDS                                   *tree-sitter-manager-commands*

                                                                 *:TSManager*
:TSManager
  Open the Tree-sitter parser management TUI.

                                                                 *:TSInstall*
:TSInstall {lang} ...
  Install parsers. >vim
    :TSInstall vim nix
<
                                                                 *:TSInstallSync*
:TSInstallSync {lang} ...
  Like |:TSInstall|, but blocks until installation finishes. Useful for
  scripted/headless setups. >vim
    :TSInstallSync vim nix
<
                                                                 *:TSUninstall*
:TSUninstall {lang} ...
  Uninstall parsers. >vim
    :TSUninstall cpp java
<
                                                                 *:TSUpdate*
:TSUpdate [{lang}] ...
:TSUpdate!
  Update parsers. >vim
    :TSUpdate rust zsh
    :TSUpdate! "force update all
<
                                                                 *:TSUpdateSync*
:TSUpdateSync [{lang}] ...
:TSUpdateSync!
  Like |:TSUpdate|, but blocks until the update finishes. Useful for
  scripted/headless setups. >vim
    :TSUpdateSync rust zsh
    :TSUpdateSync! "force update all
<

7. KEYBINDINGS                             *tree-sitter-manager-keybindings*

These keybindings are active inside the `:TSManager` TUI window.

  Key        Action ~
  ───────────────────────────────────────
  `i`        Install parser under cursor
  `x`        Remove parser under cursor
  `u`        Update parser under cursor
  `r`        Refresh installation status
  `q`        Close window
  `<Esc>`    Close window

8. CUSTOM REPOSITORIES                     *tree-sitter-manager-custom-repos*
                                           *tree-sitter-manager-opt-languages*

The `languages` option accepts a table that overrides built-in language
definitions or adds new ones. This avoids modifying the plugin source.

Each entry has the following shape: >lua
  languages = {
    <lang> = {
      install_info = {
        url      = "https://github.com/...",  -- required
        location = nil,       -- subdirectory inside the repo (optional)
        revision = nil,       -- commit SHA to pin (optional)
        branch   = nil,       -- branch name (optional)
        generate = false,     -- run `tree-sitter generate` before building
        queries  = "queries", -- queries folder in the cloned repo (optional)
      },
      requires = {},  -- list of language names that must be installed first
    },
  }
<

Override a built-in with a fork: >lua
  require("tree-sitter-manager").setup({
    languages = {
      cpp = {
        install_info = {
          url = "https://github.com/myfork/tree-sitter-cpp",
          revision = "abc1234",
          queries = "queries",
        },
      },
    },
  })
<

Add a new language: >lua
  require("tree-sitter-manager").setup({
    languages = {
      mylang = {
        install_info = {
          url = "https://github.com/someone/tree-sitter-mylang",
          queries = "queries/subdir",
        },
      },
    },
  })
<

If you are only setting the `url` field, there is a shortcut: >lua
  require("tree-sitter-manager").setup({
    languages = { mylang = "https://github.com/someone/tree-sitter-mylang" },
  })
<

------------------------------------------------------------------------------
                                    *tree-sitter-manager-install_info-location*
languages.<lang>.install_info.location ~
  Type: `string`
  Default: `nil`

  If `grammar.js` is not located in the repository's root you can configure it
  with the `location` option.

------------------------------------------------------------------------------
                                     *tree-sitter-manager-install_info-queries*
languages.<lang>.install_info.queries ~
  Type: `string`
  Default: `nil`

  If unset, bundled `runtime/queries/<lang>/` will be symlinked to the
  `query_dir` location. Otherwise, set it to the relative path of the queries
  directory in the repository, often `"queries"`.

9. HIGHLIGHTING                           *tree-sitter-manager-highlighting*

Tree-sitter highlighting is enabled by default for all installed parsers.
It is applied via a `FileType` autocmd that calls |vim.treesitter.start()|.

Opt-out for specific languages: >lua
  require("tree-sitter-manager").setup({
    nohighlight = { "yaml", "zsh" },
  })
<

Opt-in mode (only listed languages): >lua
  require("tree-sitter-manager").setup({
    highlight = { "lua", "c", "rust" },
  })
<

Disable completely: >lua
  require("tree-sitter-manager").setup({
    highlight = false,
  })
<

10. API                                            *tree-sitter-manager-api*

The main module is loaded via `require("tree-sitter-manager")`. Sub-modules
are available as: >lua
  local installer = require("tree-sitter-manager.installer")
  local util      = require("tree-sitter-manager.util")
<

------------------------------------------------------------------------------
10.1 INSTALLER                           *tree-sitter-manager-api-installer*
                                         *tree-sitter-manager-installer*

------------------------------------------------------------------------------
                                         *tree-sitter-manager-installer-install*
`installer.install(languages, callback)`
  Install one or more parsers asynchronously.

  `languages` - `string|string[]`: language name(s) to install
  `callback`  - `fun(out: Status)`: called for each language with its
                result. `Status` is `{ ok: boolean, error?: string }`.

  Dependencies listed in `requires` are resolved and installed
  automatically. Languages in `assume_installed` are skipped.

  >lua
    installer.install("lua")
    installer.install({ "python", "rust" }, function(out)
      if out.ok then
        print("done")
      end
    end)
<

------------------------------------------------------------------------------
                                          *tree-sitter-manager-installer-remove*
`installer.remove(languages, callback)`
  Remove one or more parsers.

  `languages` - `string|string[]`: language name(s) to remove
  `callback`  - `fun(out: Status)`: called once after all removals complete.

  >lua
    installer.remove("cpp")
    installer.remove({ "java", "kotlin" })
<

------------------------------------------------------------------------------
                                          *tree-sitter-manager-installer-update*
`installer.update(languages, callback)`
  Update one or more parsers (remove + reinstall).

  `languages` - `string|string[]`: language name(s) to update
  `callback`  - `fun(out: Status)`: called for each language.

  >lua
    installer.update("lua")
    installer.update({ "python", "rust" })
<

------------------------------------------------------------------------------
                                            *tree-sitter-manager-installer-wait*
`installer.wait(languages, timeout)`
  Block the main loop until none of the given languages are still
  installing.

  `languages` - `string|string[]`: language name(s) to wait for
  `timeout`   - `number`: max time in ms (default: `math.huge`)

  Returns `true` if all finished, `false` on timeout.

  >lua
    installer.install("lua")
    installer.wait("lua", 30000) -- wait up to 30s
<

------------------------------------------------------------------------------
                                      *tree-sitter-manager-installer-installing*
`installer.installing`
  Type: `table<string, boolean>`

  Tracks languages currently being installed. A key is present while the
  install is in progress and removed when it completes.

------------------------------------------------------------------------------
                                          *tree-sitter-manager-installer-status*
`installer.status`
  Type: `table<string, Status>`

  Tracks the last known status for each language.
  `Status` = `{ ok: boolean, error?: string }`

10.2 UTIL                                     *tree-sitter-manager-api-util*

------------------------------------------------------------------------------
                                         *tree-sitter-manager-util-is_installed*
`util.is_installed(lang)`
  Returns `true` if the parser for `lang` is installed, `false` otherwise.
  Languages in `assume_installed` always return `true`.

------------------------------------------------------------------------------
                                        *tree-sitter-manager-util-not_installed*
`util.not_installed(lang)`
  Negation of |tree-sitter-manager-util-is_installed|.

------------------------------------------------------------------------------
                                        *tree-sitter-manager-util-get_filetypes*
`util.get_filetypes(lang)`
  Returns `string[]` of filetypes associated with `lang`, excluding
  invalid/ambiguous filetypes.

------------------------------------------------------------------------------
                                         *tree-sitter-manager-util-get_requires*
`util.get_requires(lang)`
  Returns `string[]` of all transitive dependencies for `lang`.

------------------------------------------------------------------------------
                                        *tree-sitter-manager-util-get_repo_info*
`util.get_repo_info(lang)`
  Returns the resolved `install_info` table for `lang`, or `nil` if the
  language is not in the effective repos.

------------------------------------------------------------------------------
                                                *tree-sitter-manager-util-ppath*
`util.ppath(lang)`
  Returns the absolute path to the compiled parser file for `lang`.

------------------------------------------------------------------------------
                                                *tree-sitter-manager-util-qpath*
`util.qpath(lang)`
  Returns the absolute path to the queries directory for `lang`.

------------------------------------------------------------------------------
                                                  *tree-sitter-manager-util-ext*
`util.ext()`
  Returns the platform-specific parser extension:
  `".so"`, `".dylib"`, or `".dll"`.

------------------------------------------------------------------------------
                                                  *tree-sitter-manager-util-run*
`util.run(args, opts)`
  Run a system command asynchronously with queue support.

  `args` - `string[]`: command and arguments
  `opts` - `table`:
    - `callback` - `fun(out: Status)`: called when the job finishes
    - `status`   - `Status`: if `status.ok` is `false`, the job is skipped
    - `queue`    - `Queue`: job queue (default: `util.global_queue`)
    - Other keys are passed through to |vim.system()|

  Returns an `AsyncJob` with:
    - `:wait(timeout?)` - block until the job finishes, returns `Status`
    - `:start()`        - start the job immediately
    - `.active`         - `boolean`, whether the job is running

  >lua
    local job = util.run({ "tree-sitter", "--version" }, {
      callback = function(out)
        print(out.output)
      end,
    })
    -- or block:
    local out = util.run({ "git", "version" }):wait()
<

------------------------------------------------------------------------------
                                             *tree-sitter-manager-util-copy_dir*
`util.copy_dir(src, dst)`
  Recursively copy a directory.

  Returns `{ ok = true }` on success, `{ ok = false, error = string }` on
  failure.

------------------------------------------------------------------------------
                                                *tree-sitter-manager-util-Queue*
`util.Queue`
  A job queue class that limits concurrent jobs to `async_size`.

  Methods:
    - `Queue:new()`          - create a new queue
    - `:add(job)`            - add a job
    - `:remove(job)`         - remove a job
    - `:find(job)`           - find a job, returns index and job
    - `:start_next_batch()`  - start queued jobs up to `async_size`

  `util.global_queue` is the default queue used by |tree-sitter-manager-util-run|.

11. KNOWN LIMITATIONS                      *tree-sitter-manager-limitations*

  - Primarily tested on macOS/Linux. Windows support may need extra work.
  - `tree-sitter` CLI must be available in `$PATH`.
  - No automatic updates: use `u` in the TUI or remove + reinstall.
  - Parser repository URLs in `repos.lua` are sourced from the archived
    nvim-treesitter repository and cannot all be manually verified.
    Please open an issue or PR if you find a broken link.
